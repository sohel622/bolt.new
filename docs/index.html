Bolt.new — ব্যাকএন্ড ডকুমেন্টেশন

bolt.new ব্রাউজারেই প্রম্পট থেকে ফুল-স্ট্যাক ওয়েব অ্যাপ বানায়। এই পেজে শুধু এর ব্যাক সাইড — সার্ভার, API রুট, LLM স্ট্রিমিং আর রানটাইম — কীভাবে কাজ করে, তা ধাপে ধাপে সাজানো হলো।

একটা সাধারণ ওয়েব অ্যাপের মতো এখানে আলাদা ডেটাবেস-সার্ভার বা REST ব্যাকএন্ড নেই। ব্যাকএন্ড বলতে এখানে মূলত তিনটি জিনিস:

01 · SERVERRemix সার্ভার রুট

Cloudflare Pages-এ চলা সার্ভারলেস ফাংশন, যেগুলো ব্রাউজার থেকে রিকোয়েস্ট নেয়।

02 · LLMLLM লেয়ার

app/lib/.server/llm/-এর ভেতরে থাকা কোড, যা AI প্রোভাইডারের (মূলত Anthropic Claude) কাছে প্রম্পট পাঠায় আর উত্তর স্ট্রিম করে ফেরত আনে। সার্ভার সাইডে থাকায় API key ব্রাউজারে ফাঁস হয় না।

03 · RUNTIMEWebContainer রানটাইম

কোড চালানোর আসল ইঞ্জিন। এটি সার্ভারে নয়, ব্যবহারকারীর ব্রাউজারের ভেতরেই Node.js চালায়। ব্যাকএন্ডের কাজ এখানে শুধু সঠিক সিকিউরিটি হেডার পাঠানো, যাতে ব্রাউজার এই রানটাইম চালাতে পারে।

মূল ধারণা

ব্যাকএন্ডের কাজ শুধু AI-এর সঙ্গে কথা বলা। ফাইল তৈরি, npm install, dev server চালানো, প্রিভিউ — সবই ঘটে ব্রাউজারের WebContainer-এ। তাই bolt.new-এর সার্ভার খরচ ও স্কেলিং অনেক হালকা।

01 আর্কিটেকচার

একজন ব্যবহারকারী প্রম্পট পাঠালে ডেটা যেভাবে ঘোরে:

1
ব্রাউজার — চ্যাট UI

ব্যবহারকারী প্রম্পট লেখে। চ্যাট কম্পোনেন্ট (app/components/chat/) পুরো কথোপকথনের হিস্ট্রি সহ POST /api/chat-এ রিকোয়েস্ট পাঠায়।

2
Remix সার্ভার রুট — api.chat.ts

Cloudflare Pages ফাংশন রিকোয়েস্ট নেয়, সিস্টেম প্রম্পট জুড়ে দেয় এবং LLM লেয়ারকে কল করে।

3
LLM লেয়ার — lib/.server/llm/

getModel() নির্বাচিত প্রোভাইডারের মডেল তৈরি করে, streamText() Vercel AI SDK দিয়ে মডেলের কাছে স্ট্রিমিং রিকোয়েস্ট পাঠায়। API key শুধু এখানেই, সার্ভারে থাকে।

4
স্ট্রিমিং রেসপন্স

AI-এর উত্তর টুকরো টুকরো (data stream) ব্রাউজারে ফিরে আসে। উত্তরের ভেতরে থাকে বিশেষ <boltArtifact> ফরম্যাটে ফাইল ও কমান্ডের নির্দেশ।

5
ব্রাউজার — মেসেজ পার্সার + Workbench

MessageParser স্ট্রিম পড়ে artifact আলাদা করে; ActionRunner প্রতিটি নির্দেশ WebContainer-এ পাঠায় — ফাইল লেখে, প্যাকেজ ইনস্টল করে, কমান্ড চালায়।

6
WebContainer — প্রিভিউ

ব্রাউজারের ভেতরের Node.js রানটাইমে dev server ওঠে, তার URL iframe প্রিভিউতে দেখায়। কোনো কোডই bolt-এর সার্ভারে রান হয় না।

লক্ষ্য করুন

এই স্ন্যাপশটে কোনো ডেটাবেস, লগইন/অথ সিস্টেম বা ফাইল স্টোরেজ সার্ভার নেই। চ্যাট হিস্ট্রি ব্রাউজারের localStorage-এ এবং প্রজেক্ট ফাইল WebContainer-এর ইন-মেমরি ফাইল সিস্টেমে থাকে।

04 API রুটসমূহ

সার্ভার সাইডে মোটা দাগে তিনটি API রুট আছে। সবগুলোই app/routes/-এ Remix resource route হিসেবে লেখা।

রুটমেথডকাজরেসপন্স
/api/chatPOSTচ্যাট মেসেজ নিয়ে সিস্টেম প্রম্পটসহ LLM-এ পাঠায়; মূল জেনারেশন এখানেই হয়স্ট্রিমিং (AI SDK data stream)
/api/enhancerPOSTব্যবহারকারীর ছোট/অস্পষ্ট প্রম্পটকে LLM দিয়ে বিস্তারিত প্রম্পটে সাজিয়ে দেয়স্ট্রিমিং টেক্সট
/api/modelsGETকোন কোন প্রোভাইডারের API key সেট করা আছে, সেই অনুযায়ী ব্যবহারযোগ্য মডেলের তালিকা দেয়JSON

/api/chat — মূল ফ্লো

রুটটির সার্ভার ফাংশন (action) ধাপে ধাপে:

  1. রিকোয়েস্ট বডি থেকে messages অ্যারে পড়ে।
  2. streamText()-কে (LLM লেয়ার) কল করে — সঙ্গে সিস্টেম প্রম্পট ও আগের সব মেসেজ।
  3. AI SDK-এর toDataStream() দিয়ে ফলাফলকে স্ট্রিমিং রেসপন্সে পরিণত করে ব্রাউজারে পাঠায়।
  4. স্ট্রিম চলাকালীন টোকেন ব্যবহার গোনা হয়; সীমা (MAX_RESPONSE_SEGMENTS) পার হলে ধারাবাহিকতা বজায় রাখতে SwitchableStream দিয়ে নতুন সেগমেন্ট শুরু হয়।
app/routes/api.chat.ts — সরলীকৃত রূপ
import { type ActionFunctionArgs } from '@remix-run/cloudflare';
import { streamText } from '~/lib/.server/llm/stream-text';

export async function action({ context, request }: ActionFunctionArgs) {
  const { messages } = await request.json();

  const result = await streamText({
    messages,
    env: context.cloudflare.env,   // API key এখান থেকে আসে
  });

  return result.toDataStream();  // স্ট্রিমিং রেসপন্স
}

উপরের কোডটি বোঝার সুবিধার জন্য সরলীকৃত — আসল ফাইলে এরর হ্যান্ডলিং, টোকেন কাউন্টিং ও সেগমেন্ট বদলের যুক্তি আরও আছে।

05 LLM লেয়ার ও স্ট্রিমিং

LLM লেয়ার থাকে app/lib/.server/llm/-তে। এর কাজ: কোন প্রোভাইডার/মডেল ব্যবহার হবে তা ঠিক করা, সিস্টেম প্রম্পট জোড়া, আর উত্তরের স্ট্রিম সাজানো।

মডেল নির্বাচন — model.ts

getModel(provider, model, env) ফাংশনটি প্রোভাইডারের নাম অনুযায়ী সংশ্লিষ্ট AI SDK প্রোভাইডার প্যাকেজ দিয়ে মডেল ইনস্ট্যান্স বানায়। প্রতিটি প্রোভাইডারের API key এনভায়রনমেন্ট ভেরিয়েবল থেকে পড়া হয় — কোনো key কোডে হার্ডকোড করা নেই। ডিফল্ট প্রোভাইডার Anthropic।

স্ট্রিমিং — stream-text.ts

  • Vercel AI SDK-এর streamText() ব্যবহার করে; maxTokens সীমা constants.ts-এর MAX_TOKENS থেকে আসে।
  • মেসেজগুলো পাঠানোর আগে প্রসেস করা হয় — আগের উত্তরের artifact অংশ কেটে ছোট করা হয়, যাতে কনটেক্সট উইন্ডো ভরে না যায়।
  • onFinish কলব্যাকে মোট টোকেন ব্যবহার হিসাব হয়।
app/lib/.server/llm/stream-text.ts — মূল অংশ (সরলীকৃত)
import { streamText as _streamText } from 'ai';
import { getModel } from '~/lib/.server/llm/model';
import { getSystemPrompt } from '~/lib/.server/llm/prompts';
import { MAX_TOKENS } from './constants';

export function streamText({ messages, env, model, provider }) {
  return _streamText({
    model: getModel(provider, model, env),
    system: getSystemPrompt(),
    maxTokens: MAX_TOKENS,
    messages: convertToCoreMessages(messages),
  });
}

কেন স্ট্রিমিং?

পুরো উত্তর শেষ হওয়া পর্যন্ত অপেক্ষা না করে টোকেন আসামাত্রই ব্রাউজারে পাঠানো হয়। ফলে ব্যবহারকারী সঙ্গে সঙ্গে লেখা দেখতে পায়, আর MessageParser স্ট্রিমের মাঝখানেই ফাইল তৈরির নির্দেশ পেলে সঙ্গে সঙ্গে WebContainer-এ কাজ শুরু হয়ে যায় — পুরো অভিজ্ঞতাটাই দ্রুত মনে হয়।

06 প্রম্পট সিস্টেম

সিস্টেম প্রম্পট থাকে app/lib/.server/llm/prompts.ts-এর getSystemPrompt()-এ। এটি মডেলকে শেখায়: WebContainer-এর সীমাবদ্ধতা (কোন কমান্ড চলবে, কোনটা চলবে না), কোন স্ট্যাকে কোড লিখতে হবে, এবং সবচেয়ে গুরুত্বপূর্ণ — উত্তর কোন ফরম্যাটে দিতে হবে।

মডেলের প্রতিটি কাজের নির্দেশ আসে artifact ফরম্যাটে:

মডেলের উত্তরের artifact ফরম্যাট
<boltArtifact id="todo-app" title="Todo App">
  <boltAction type="file" filePath="src/App.tsx">
    // এখানে ফাইলের পুরো কনটেন্ট
  </boltAction>
  <boltAction type="shell">
    npm install
  </boltAction>
  <boltAction type="start">
    npm run dev
  </boltAction>
</boltArtifact>
Action typeঅর্থকে কার্যকর করে
fileনির্দিষ্ট পাথে ফাইল তৈরি/আপডেটActionRunner → WebContainer FS
shellটার্মিনালে কমান্ড চালানো (যেমন npm install)ActionRunner → WebContainer শেল
startdev server চালু করা (দীর্ঘমেয়াদি প্রসেস)ActionRunner → WebContainer শেল

ব্রাউজারের app/lib/runtime/message-parser.ts স্ট্রিম পড়তে পড়তে এই ট্যাগগুলো আলাদা করে, আর app/lib/runtime/action-runner.ts প্রতিটি action WebContainer-এ চালায়। অর্থাৎ প্রম্পটের ফরম্যাটই হলো ব্যাকএন্ড ও রানটাইমের মধ্যে চুক্তি (contract)।

07 WebContainer রানটাইম

WebContainer হলো StackBlitz-এর প্রযুক্তি — ব্রাউজারের ভেতরে চলা একটি মাইক্রো-OS/Node.js রানটাইম। bolt.new-এ:

  • app/lib/webcontainer/index.ts অ্যাপ লোডের সময় একবারই (singleton) WebContainer.boot() করে।
  • ফাইল সিস্টেম, শেল প্রসেস, npm install, dev server — সব এই রানটাইমের ভেতরে।
  • dev server চালু হলে server-ready ইভেন্টে URL পাওয়া যায়, সেটাই প্রিভিউ iframe-এ বসে।

ব্যাকএন্ডের ভূমিকা: COOP/COEP হেডার

WebContainer-এর জন্য ব্রাউজারে SharedArrayBuffer দরকার, আর তার শর্ত হলো পেজটিকে cross-origin isolated হতে হবে। তাই সার্ভার প্রতিটি রেসপন্সে এই দুটি হেডার পাঠায় (সার্ভার এন্ট্রি / কনফিগে সেট করা):

রেসপন্স হেডার
Cross-Origin-Embedder-Policy: require-corp
Cross-Origin-Opener-Policy: same-origin

এই হেডার না থাকলে WebContainer বুট হবে না — এটাই এই প্রজেক্টে ফ্রন্টএন্ড ও ব্যাকএন্ডের সবচেয়ে গুরুত্বপূর্ণ সংযোগবিন্দুগুলোর একটি।

08 এনভায়রনমেন্ট ভেরিয়েবল

API key কখনো কোডে লেখা হয় না। লোকালে .env.local ফাইলে, আর Cloudflare-এ Pages-এর environment settings / wrangler.toml-এর vars-এ রাখা হয়। অন্তত একটি প্রোভাইডারের key থাকলেই অ্যাপ চলবে।

.env.local — নমুনা
# মূল প্রোভাইডার (ডিফল্ট)
ANTHROPIC_API_KEY=sk-ant-...

# ঐচ্ছিক — অন্য প্রোভাইডার চালু করতে
OPENAI_API_KEY=sk-...
GOOGLE_GENERATIVE_AI_API_KEY=...
GROQ_API_KEY=...
OPEN_ROUTER_API_KEY=...
DEEPSEEK_API_KEY=...
MISTRAL_API_KEY=...
XAI_API_KEY=...

# লোকাল মডেল (Ollama) ব্যবহার করলে
OLLAMA_API_BASE_URL=http://localhost:11434

# ডিফল্ট মডেল বদলাতে চাইলে
DEFAULT_MODEL=claude-3-5-sonnet-latest
DEFAULT_PROVIDER=Anthropic

নিরাপত্তা

.env.local কখনো GitHub-এ পুশ করবেন না — এটি .gitignore-এ থাকে। key একবার পাবলিক হয়ে গেলে তা বাতিল (revoke) করে নতুন key বানাতে হয়; ফাইল থেকে মুছে ফেললেও git history-তে থেকে যায়।

09 লোকালি চালানো

শর্ত: Node.js 18+ এবং pnpm ইনস্টল থাকতে হবে। এটি ডেস্কটপ/ল্যাপটপের জন্য — ফোনে সরাসরি চালানো যাবে না।

  1. রিপো ক্লোন করুন
    Terminal
    git clone https://github.com/sohel622/bolt.new.git
cd bolt.new
  2. ডিপেন্ডেন্সি ইনস্টল করুন
    Terminal
    pnpm install
  3. API key বসান.env.example কপি করে .env.local বানিয়ে অন্তত ANTHROPIC_API_KEY বসান (আগের অংশ দেখুন)।
  4. Dev server চালু করুন
    Terminal
    pnpm run dev
    ব্রাউজারে http://localhost:5173 খুলুন। WebContainer-এর জন্য Chrome/Edge-এর মতো Chromium ব্রাউজার সবচেয়ে নির্ভরযোগ্য।

10 Cloudflare Pages-এ ডেপ্লয়

এই প্রজেক্টের অফিসিয়াল হোস্টিং Cloudflare Pages — Remix অ্যাপটি সেখানকার ফাংশন হিসেবে চলে।

  1. বিল্ড যাচাই করুনpnpm run build চালিয়ে দেখুন বিল্ড সফল হয় কিনা।
  2. Wrangler দিয়ে ডেপ্লয়
    Terminal
    pnpm run deploy
    ভেতরে wrangler pages deploy চলে; প্রথমবার Cloudflare অ্যাকাউন্টে লগইন চাইবে।
  3. প্রোডাকশন key সেট করুনCloudflare Dashboard → Pages → প্রজেক্ট → Settings → Environment variables-এ API key গুলো যোগ করুন, তারপর প্রয়োজনে আবার ডেপ্লয় দিন।

GitHub Pages সম্পর্কে

এই ডকুমেন্ট পেজটি নিজে একটি স্ট্যাটিক পেজ — GitHub Pages-এ এমন স্ট্যাটিক ডকুমেন্ট সহজেই হোস্ট করা যায়। কিন্তু bolt.new অ্যাপটি নিজে GitHub Pages-এ চলবে না, কারণ GitHub Pages শুধু স্ট্যাটিক ফাইল দেয় — Remix সার্ভার রুট (/api/chat) চালানোর কোনো সার্ভার সেখানে নেই। অ্যাপের জন্য Cloudflare Pages-ই লাগবে।
